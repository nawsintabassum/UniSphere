# UniSphere

Complete frontend-only Student Campus Management Web Application.

## Technology
HTML5, CSS3, Vanilla JavaScript, LocalStorage.

## Run in VS Code
Open the folder and run `index.html` with Live Server. No Node.js, backend, database, API key or installation is required.

## Demo Login
Any Student ID + any valid email + any password.

## LocalStorage keys
users, currentUser, profile, courses, results, routine, assignments, events, notices, clubs, marketplace, lostFound, messages, notifications, settings.
